# TudiMedia AI Platform

Production engineering workspace for designing and building an enterprise AI-powered media platform from architecture through deployment.

## Repository layout

| Directory | Purpose |
| --- | --- |
| `apps/` | User-facing applications, including the web console. |
| `services/` | Deployable backend, worker, search, and AI services. |
| `packages/` | Shared libraries, types, configuration, and UI components. |
| `infrastructure/` | Infrastructure-as-code, deployment manifests, and environment configuration. |
| `docs/` | Product, architecture, delivery, API, security, and AI documentation. |
| `tests/` | Cross-service integration, end-to-end, performance, and security tests. |
| `scripts/` | Safe, documented development and operational automation. |

See [docs/PRD.md](docs/PRD.md) for the product direction and [docs/SYSTEM_ARCHITECTURE.md](docs/SYSTEM_ARCHITECTURE.md) for the system design.

The collaboration and release approach is defined in [docs/GIT_BRANCH_STRATEGY.md](docs/GIT_BRANCH_STRATEGY.md).
